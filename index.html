Car Sniper

Find legitimately underpriced private-party used cars shortly after they're posted — before other buyers find them.

What it does

Car Sniper is a pipeline that runs on your own machine. It watches marketplaces, decides what's actually a deal, and tells you which listings are worth a closer look — with the evidence behind each call.

Collect

Pulls listings from Facebook Marketplace, Craigslist, and AutoTrader (more collectors are pluggable).

Value

Estimates a fair price from comparable vehicles — same model, ±2 years, ±40% mileage — and a mileage/age adjustment.

Screen risk

Decodes the VIN (free NHTSA data), flags salvage/title issues, recalls, and scam patterns.

Rank deals

Surfaces the listings sitting meaningfully below comparable prices, with estimated savings and supporting comps.

How a "deal" is decided

1. Collect listings → 2. Value vs comps → 3. Screen risk → 4. Rank & alert
Honesty box. A price 20% below genuinely comparable vehicles triggers closer investigation, not an automatic "bargain." Comps are asking prices and skew high; the tool does no mechanical, structural, or vehicle-history lookups. A listing that clears the bar is a candidate worth your eyes — not a guarantee.

Example configuration

The pipeline is configured, not hardcoded. A typical setup monitors the New England states (Massachusetts, Rhode Island, New Hampshire, Connecticut) for specific models such as the Lexus ES 350 and Acura TLX, and alerts when a private-party listing looks underpriced versus its cohort.

Speed is the whole point

The edge isn't a better model — it's being first. The value comes from catching a correctly-priced private-party listing within minutes of posting, while it's still buried under stale inventory. That's why collectors, valuation, and risk screening are built to run on a schedule you control.

Where the code lives

The source is kept private. If you'd like to run it yourself, reach out for an invite — the pipeline is straightforward to stand up on any machine with Python and a browser.
